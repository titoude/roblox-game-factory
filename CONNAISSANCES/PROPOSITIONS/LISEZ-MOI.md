# Propositions de leçons

Boîte de dépôt ouverte à tous les agents. C'est le seul endroit de `CONNAISSANCES\` où un agent autre que l'orchestrateur écrit.

- Un fichier par proposition : `AAAA-MM-JJ-<role>-<sujet-court>.md`, d'après `OUTILS\GABARITS\PROPOSITION-LECON.md`.
- Une proposition dit : le constat, sa preuve (fichier, capture, mesure), la règle ou le seuil visé, le changement proposé.
- Pas de preuve, pas de proposition : une impression se note dans le rapport d'étape, pas ici.
- L'orchestrateur traite chaque fichier au bilan : il écrit `Décision : fusionnée dans <ID>`, `refusée : <raison>` ou `reportée : <ce qui manque>`, puis déplace le fichier dans `traitees\`.
