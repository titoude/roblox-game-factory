# Veille

Commune à tous les jeux. Procédure : `..\PROCEDURES\01-VEILLE-NAVIGATEUR.md`. Sources et limites : `..\CONNAISSANCES\SOURCES-VEILLE.md`.

| Fichier | Contenu | Qui écrit |
|---|---|---|
| `RELEVES\AAAA-MM-JJ\<veilleur>-<source>.md` | Relevés bruts d'un tour, un fichier par veilleur | Les veilleurs |
| `RELEVES\AAAA-MM-JJ\captures\` | Captures de travail, hors git, purgées au tour suivant | Les veilleurs |
| `TENDANCES.md` | Synthèse cumulative : chaque tour comparé au précédent | L'orchestrateur |
| `IDEES-CANDIDATES.md` | Thèmes pressentis, avec ce qui manque à leur corpus | L'orchestrateur |
| `instantanes.csv` | CCU datés d'univers repérés (`OUTILS\instantane-univers.ps1`) | L'orchestrateur |
| `univers-suivis.txt` | Liste d'univers validée pour les instantanés (50 au plus) | L'orchestrateur |

Un relevé ne se corrige pas après coup : une erreur se signale dans le tour suivant.
